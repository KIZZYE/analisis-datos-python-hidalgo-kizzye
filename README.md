# Análisis de Datos con Python

Repositorio del curso **Análisis de Datos con Python** — Kizzye Hidalgo.

## Descripción

Este repositorio contiene los notebooks, funciones y reportes desarrollados a lo largo del curso, incluyendo ejercicios de introducción a Python, fundamentos del lenguaje, y funciones/modularización aplicadas a un caso de análisis de datos de motores (voltaje, corriente y temperatura).
